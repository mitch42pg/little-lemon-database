## Little Lemon Database Project (PNG-based ERD version)

### Overview
This project implements a database for Little Lemon that supports bookings, customers, orders, menu items, staff, and delivery status.  
The schema was recreated to match the provided ER diagram.

### Tools Used
- MySQL
- Python
- Tableau
- GitHub

### ER Diagram
The ER diagram is included in `docs/ERD.md` (Mermaid format).

### How to run
1. Run: `sql/01_schema.sql`
2. Run: `sql/02_procedures.sql`
3. (Optional) Run: `sql/03_seed.sql`
